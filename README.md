One original one-line dad joke for the [make.fun bounty "The One-Liner Groan-Off"](https://make.fun/bounty/u-alfasurya91-the-one-liner-groan-off-5a1febd5) ($2).

## The joke

> I keep a pencil behind my ear — it helps me draw the line when the kids push their luck.

## How it works

`main.ts` writes that single line (at most 140 characters) to `/output/entry.txt`,
where the bounty judge reads it. Nothing else is needed: no code, no data, just the line.

Run it with Node 22.18 or later:

```sh
node main.ts
```
